# GitHub Analyzer 1.4.0

This release improves repository synchronization, authorship management, offline
analysis and the reliability of saved results and exports.

## Highlights

- Incremental downloads reuse saved commits, unchanged source files and shared
  branch histories. Selective refresh updates only the chosen repositories.
- Download cancellation interrupts queued and active tasks. Expensive API request
  admissions are spaced to reduce concurrent bursts.
- The redesigned authorship editor supports account integration, multiple
  selection and drag and drop, with local recalculation from saved original data.
- Large Java source scans avoid per-line allocations. CSV export reuses team
  metrics, protects existing files on failure and reports export errors.
- Contributor activity uses captured author dates, with a fallback for older data.
  Displayed percentages and CSV numbers follow consistent Spanish conventions.
- Configuration supports runtime GITHUB_TOKEN credentials, restricted local file
  permissions and recovery of interrupted configuration saves.
- Dependency integrity checks, a CycloneDX SBOM and vulnerability-audit automation
  cover bundled and embedded libraries.
- Documentation includes a consolidated technical and efficiency audit, with
  remaining work ranked by impact, relevance and effort.

## Downloads

- `github-analyzer-1.4.0.jar`: self-contained desktop application; requires Java 17
  or newer. No separate library installation is needed.
- `github-analyzer-1.4.0.jar.sha256`: checksum for verifying the JAR.
- `dependencies.lock.json`: reviewed bundled dependency inventory.
- `sbom.cdx.json`: CycloneDX source-distribution inventory, including test-only
  components; the test runner is excluded from the runnable JAR.

Keep an existing local `resources/` directory when upgrading. Credentials,
repository configuration, original downloads and authorship assignments are not
included in release assets. Previously saved downloads remain readable.

## Validation and limits

Local verification includes 269 passing Java tests, 24 passing dependency-audit
tests, four passing release-layout checks, dependency/SBOM verification and
packaging checks. All seven JARs matched Maven Central, and a complete OSV scan
of 27 components reported no findings or errors on 17 November 2026. The benchmark comparison runs offline against the previous
source-processing baseline. Live GitHub behavior and interactive desktop use
were not exercised in this final review.

Cancellation is cooperative; an I/O operation that ignores interruption may take
time to return. Partial-download checkpoints and additional parallelism within a
single repository remain future work. See the consolidated audit for details.
