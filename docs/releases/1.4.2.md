# GitHub Analyzer 1.4.2

This patch release preserves the licenses and notices of bundled runtime
dependencies in the runnable JAR.

## Changes

- Dependency licenses and notices are kept byte for byte in separate directories
  under `META-INF/licenses/`, so documents with the same name do not overwrite
  one another when libraries are bundled.
- The JAR includes the supplemental MIT license for the GitHub API library.
- The Windows and POSIX build scripts compile application sources as UTF-8.
- The release workflow verifies the legal texts and runtime contents of the JAR
  before publishing it.
- The analysis area uses a 30% repository overview, 50% people table and 20%
  file-type tree, preserving these proportions when the window is resized.
- The upper-left header displays the University of Deusto anniversary logo and
  its Spanish and Basque names, aligned with the action buttons. The JPG is
  bundled for offline use and links to the university website when clicked.
- Narrow windows use compact action labels to keep the bilingual university
  block clear of all toolbar buttons. Full labels return when the window grows;
  the toolbar height and 30/50/20 analysis split are unchanged.
- The README reflects the actual source layout, platform-specific commands,
  Eclipse refresh requirements, offline configuration and CI coverage.
- Desktop regression checks verify autonomous process exit with code 0, including
  pending operations and cancelled downloads.

The existing v1.4.2 tag and download assets are refreshed in place for these
interface and documentation changes; no additional version is introduced.

## Downloads

- `github-analyzer-1.4.2.jar` is the self-contained desktop application and
  requires Java 17 or newer.
- `github-analyzer-1.4.2.jar.sha256` is the SHA-256 checksum for the JAR.
- `dependencies.lock.json` and `sbom.cdx.json` describe the bundled dependencies
  and the source distribution.

Keep your existing `resources/` directory when upgrading.

## Validation

For the original package, on native Windows 11 with Temurin 17, all 282 Java
tests passed. The build
completed without command prompt warnings, and the JAR verifier confirmed all
14 legal texts, Java 17 classes, runtime libraries and icons. The packaged app
started with synthetic offline data, displayed repository icons and closed
normally without credentials.

The responsive toolbar correction was validated on native macOS ARM64 with
Temurin 17.0.21.1+2 in an isolated copy using synthetic data. At 760 pixels wide,
the university block and action buttons no longer overlap. Resizing to 1200 pixels
restores the full labels, and returning to 760 preserves the compact layout and
30/50/20 panel proportions. All 282 unit tests, graphical checks, process-exit
regressions and runnable JAR content/license verification passed.
