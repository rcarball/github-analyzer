# GitHub Analyzer 1.4.2

This patch release preserves the licenses and notices of bundled runtime
dependencies in the runnable JAR.

## Changes

- Dependency licenses and notices are kept byte for byte in separate directories
  under `META-INF/licenses/`, so documents with the same name do not overwrite
  one another when libraries are bundled.
- The JAR includes the supplemental MIT license for the GitHub API library.
- The Windows and POSIX build scripts compile application sources as UTF-8.
- The release workflow verifies the legal texts and runtime contents of the JAR
  before publishing it.

## Downloads

- `github-analyzer-1.4.2.jar` is the self-contained desktop application and
  requires Java 17 or newer.
- `github-analyzer-1.4.2.jar.sha256` is the SHA-256 checksum for the JAR.
- `dependencies.lock.json` and `sbom.cdx.json` describe the bundled dependencies
  and the source distribution.

Keep your existing `resources/` directory when upgrading.

## Validation

On native Windows 11 with Temurin 17, all 282 Java tests passed. The build
completed without command prompt warnings, and the JAR verifier confirmed all
14 legal texts, Java 17 classes, runtime libraries and icons. The packaged app
started with synthetic offline data, displayed repository icons and closed
normally without credentials.
