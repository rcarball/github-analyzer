# GitHub Analyzer 1.4.1

This patch release improves the desktop layout on small displays and validates
the download and recovery workflows on Windows 11.

## Changes

- The main window reflows the repository overview into fewer columns when space
  is limited. Lists and tables scroll independently as needed.
- The download dialog keeps progress, status and the Cancel download button
  visible when resized. Closing a warning with its X or choosing Keep
  downloading leaves downloads running. Cancelling from the progress dialog
  keeps completed downloads and leaves the application open.
- Removing repositories from the configuration updates the statistics and CSV
  while retaining their original downloads for later reuse.
- The Windows test launchers use a matched JDK, support paths with spaces,
  propagate errors and clean up temporary test files after Ctrl+C.
- Recovery closes unreadable snapshot files before replacement, allowing Windows
  to rebuild a damaged snapshot after saving a recovery copy.

## Downloads

- `github-analyzer-1.4.1.jar` contains the desktop application and requires Java 17
  or newer.
- `github-analyzer-1.4.1.jar.sha256` verifies the JAR.
- `dependencies.lock.json` and `sbom.cdx.json` describe the bundled dependencies
  and the source distribution.

Keep your existing `resources/` directory when upgrading. The release files
exclude credentials, repository lists, original downloads and authorship data.

## Validation

On native Windows 11 with Temurin 25.0.4.1, all 282 Java tests passed. Desktop
checks covered compact window sizes, default and 150% Java2D scaling, close
warnings and download cancellation. Launcher checks covered JDK selection,
paths with spaces and accented characters, error exit codes, Ctrl+C and
temporary-file cleanup. The desktop checks used offline fixtures.
