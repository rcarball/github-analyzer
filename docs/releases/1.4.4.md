# GitHub Analyzer 1.4.4

This patch release makes authorship management more compact, improves contribution
colors and icons, and fixes download activity animation on macOS.

## Changes

- The authorship editor replaces the wide original-identity table with a compact
  **Original identity** selector. **Select multiple…**, **Move to…** and
  **Separate selected identities** retain individual and batch operations with undo.
- The selected person's heading includes the assigned identity count. Java commits
  appear beside the contribution description and observed share, separated by **·**.
  Controls adapt to narrow panels with vertical scrolling and wrapped contribution
  information. Summary blocks align their numbers and text to the right.
- Missing GitHub logins display **No linked GitHub account**, distinguishing a
  missing linked account from the original Git name and email recorded in commits.
- Balanced and high contributions use green text and pale green row backgrounds.
  Teacher and excluded accounts use softer gray shading. Low-contribution rows
  retain red or orange indicators. Text and percentage-bar colors preserve at
  least 4.5:1 contrast, including selected rows and dark table backgrounds.
- Updated contribution icons show an exclamation mark, sad face, check mark and
  rocket. The very-low contribution resource is named **very-low.png** consistently
  in the application, documentation and packaged JAR.
- The lower download activity bar uses a portable moving blue segment instead of
  relying on native macOS animation. It stays six pixels high, spans the available
  width beside **Cancel download**, and remains active through final local saves.
  The upper bar continues to count finished repository attempts.
- Documentation covers the new editor, colors, icons and progress indicators.
  Test scripts compile UTF-8 sources consistently. JAR verification rejects missing
  or incorrectly capitalized icon references, and regression checks cover icon
  loading, animation, contrast and the resized download dialog.

## Downloads

- `github-analyzer-1.4.4.jar` is the self-contained desktop application and
  requires Java 17 or newer.
- `github-analyzer-1.4.4.jar.sha256` is the SHA-256 checksum for the JAR.
- `dependencies.lock.json` and `sbom.cdx.json` describe the bundled dependencies
  and source distribution.

Keep the existing external `resources/` directory when upgrading. Credentials,
repository settings, original downloads and authorship assignments remain intact;
this release does not change their formats or contribution-classification rules.

## Validation

Local verification passed all 286 Java tests and all six macOS desktop regression
checks, including cancellation and application shutdown. Offline checks passed
for dependency auditing, release layouts and launcher behavior; Windows-specific
launcher cases were skipped on macOS. The runnable JAR and its packaged icons,
Java 17 bytecode, runtime classes and license texts were verified.

Pull-request CI runs the Java 17 test and packaging matrix on Linux, macOS and
Windows, plus Linux desktop regression checks under Xvfb. The release workflow
validates the merged tag, reruns tests, verifies the JAR and publishes it with its
checksum and dependency inventories.
